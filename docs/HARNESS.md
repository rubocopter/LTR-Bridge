# D3D11 x64 temporal harness

Status: **implemented foundation; validation pending**.

The Phase 1 harness is a controlled D3D11 x64 research renderer. It currently separates projection jitter from ground-truth camera/rigid-object motion and exposes scene, depth, and motion diagnostic views.

Build, host, visual, performance, alternative-MV-provider, backend, SR, and stereo validation remain pending.
